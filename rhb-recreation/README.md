# RHB Group UI Recreation

High-fidelity frontend recreation of [rhbgroup.com](https://www.rhbgroup.com/index.html) and the [Premier](https://www.rhbgroup.com/overview/premier/index.html) page for a frontend assignment.

This is a **demo/prototype**. Branding, photography and copy are reconstructed with placeholder assets. It is not an official RHB website.

## Stack

- React + TypeScript
- Vite
- Tailwind CSS v4
- React Router
- Lucide React

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Routes

- `/` — Home recreation
- `/premier` — Premier recreation
- Other navigation items open working placeholder pages

## Notes

- Header shrinks on scroll (120px → 88px) to match the reference.
- Hero and Premier banners use locally generated photographic placeholders with the same 1920×675 / mobile portrait treatment.
- Statistics animate when they enter the viewport.
